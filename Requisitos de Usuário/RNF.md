# 1. Requisitos Não Funcionais

<p align="justify">A <i>Tabela 2</i> contém os Requisitos Não Funcionais (RNF) do site, considerando usabilidade, organização visual e manutenção do projeto.</p>

| ID    | Requisito NF | Categoria/Tipo | Prioridade | Requisitos Relacionados |
| :---: | :-- | :--: | :--: | :--: |
| RNF01 | O site deve ser responsivo para funcionar bem em computador e celular. | Produto/Usabilidade | Alta | RF01, RF04, RF07 |
| RNF02 | O site deve usar HTML e CSS simples, sem dependências externas obrigatórias. | Organizacional/Implementação | Alta | RF01, RF06, RF07 |
| RNF03 | Os arquivos principais devem ficar organizados em páginas HTML, `style.css` e `assets/`. | Organizacional/Manutenibilidade | Média | RF06, RF09 |
| RNF04 | O cabeçalho deve permitir navegação entre Início e Agentes sem ficar visualmente poluído. | Produto/Usabilidade | Alta | RF05, RF06 |
| RNF05 | O contraste entre texto e fundo deve permitir boa leitura. | Produto/Acessibilidade | Alta | RF01, RF10 |
| RNF06 | As imagens usadas no layout devem carregar por caminhos relativos dentro da pasta `assets/`. | Produto/Portabilidade | Média | RF09 |
| RNF07 | A página de agentes deve manter a mesma identidade visual da página inicial. | Produto/Consistência | Média | RF06, RF07, RF08 |
