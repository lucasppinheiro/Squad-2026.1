# 1. Requisitos Funcionais

<p align="justify">A <i>Tabela 1</i> contém os Requisitos Funcionais (RF) do site informativo sobre Valorant, levantados a partir da proposta atual do projeto.</p>

| ID   | Requisito | Prioridade | Requisitos Relacionados |
| :--: | :-- | :--: | :--: |
| RF01 | O usuário deve poder visualizar uma introdução clara sobre o que é Valorant. | Alta | US01 |
| RF02 | O usuário deve poder entender o objetivo básico de uma partida de Valorant. | Alta | US01 |
| RF03 | O usuário deve poder consultar em quais plataformas Valorant está disponível. | Média | US02 |
| RF04 | O usuário deve poder visualizar a ordem dos elos competitivos. | Alta | US03 |
| RF05 | O usuário deve poder acessar a página inicial pelo menu do cabeçalho. | Média | US04 |
| RF06 | O usuário deve poder acessar uma página própria sobre agentes pelo menu do cabeçalho. | Alta | US05 |
| RF07 | A página de agentes deve apresentar informações básicas sobre agentes de Valorant. | Alta | US05 |
| RF08 | A página de agentes deve explicar as classes/funções dos agentes: Duelista, Iniciador, Controlador e Sentinela. | Alta | US06 |
| RF09 | O sistema deve exibir imagens relacionadas ao jogo, como logo, elos e elementos visuais dos agentes. | Média | US01, US03, US05 |
| RF10 | O conteúdo deve ser apresentado em uma linguagem simples para iniciantes. | Alta | US01, US02, US03, US05, US06 |
