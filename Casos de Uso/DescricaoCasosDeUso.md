# 1. Descrições dos Casos de Uso

<p align="justify">Este documento apresenta as descrições textuais dos principais casos de uso do site informativo sobre Valorant.</p>

| ID | Caso de Uso | Ator Principal | Descrição | Pré-condição | Fluxo Principal | Pós-condição |
| :--: | :-- | :-- | :-- | :-- | :-- | :-- |
| UC01 | Visualizar introdução sobre Valorant | Visitante | Permite que o visitante entenda o que é Valorant e qual é a proposta básica de uma partida. | O visitante acessa o site pelo navegador. | O visitante abre a página inicial; lê a seção de introdução; identifica que o jogo é de tiro tático em equipes. | O visitante entende a ideia geral do jogo. |
| UC02 | Consultar plataformas disponíveis | Visitante | Permite que o visitante veja onde Valorant pode ser jogado. | O visitante está na página inicial. | O visitante acessa a seção de plataformas; visualiza PC, PlayStation 5 e Xbox Series X\|S. | O visitante identifica se possui uma plataforma compatível. |
| UC03 | Consultar elos competitivos | Visitante | Permite que o visitante conheça a ordem dos elos do modo competitivo. | O visitante está na página inicial. | O visitante acessa a seção de elos; visualiza a imagem de referência; lê a lista de elos em ordem. | O visitante entende a progressão competitiva básica. |
| UC04 | Acessar informações sobre agentes | Visitante | Permite que o visitante navegue para uma página ou seção dedicada aos agentes de Valorant. | A navegação principal está disponível. | O visitante usa o menu do site; acessa o conteúdo de agentes quando disponível; lê a explicação inicial. | O visitante entende que agentes possuem funções diferentes no time. |
| UC05 | Entender classes dos agentes | Visitante | Permite que o visitante compreenda as classes Duelista, Iniciador, Controlador e Sentinela. | O conteúdo de agentes está disponível. | O visitante acessa a área de agentes; lê as descrições das classes; compara as funções. | O visitante reconhece a função básica de cada classe. |
