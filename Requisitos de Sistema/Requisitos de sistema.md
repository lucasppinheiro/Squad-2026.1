# 1. Requisitos de Sistema

<p align="justify">Este documento descreve os requisitos de sistema para o site estático do projeto Squad-2026.1.</p>

| ID   | Requisito de Sistema | Tipo | Prioridade |
| :--: | :-- | :--: | :--: |
| RS01 | O sistema deve ser um site estático composto por HTML, CSS e imagens locais. | Implementação | Alta |
| RS02 | O arquivo principal da aplicação deve ser `index.html`. | Estrutura | Alta |
| RS03 | A estilização visual deve estar concentrada no arquivo `style.css`. | Estrutura | Alta |
| RS04 | As imagens utilizadas pelo site devem ficar na pasta `assets/`. | Estrutura | Alta |
| RS05 | O site deve funcionar ao abrir o arquivo `index.html` diretamente no navegador. | Execução | Alta |
| RS06 | O layout deve se adaptar a telas de desktop e celular por meio de regras responsivas no CSS. | Usabilidade | Alta |
| RS07 | O conteúdo inicial deve cobrir introdução ao jogo, plataformas disponíveis e sistema de elos. | Conteúdo | Alta |
| RS08 | O sistema deve conter uma página de agentes acessível pela navegação principal. | Estrutura | Alta |
| RS09 | A página de agentes deve manter o mesmo arquivo CSS da página inicial para preservar identidade visual. | Manutenção | Média |
| RS10 | O projeto deve manter a estrutura simples para facilitar a continuidade por outras pessoas do grupo. | Manutenção | Média |
